# 猫城来信

一款围绕校园猫咪救助展开的公益叙事网页游戏。玩家通过地图探索、事件选择和资源分配，决定每一天的照护行动，并在七日交接中看到选择留下的结果。

**[在线试玩](https://catcityletters.xyz/)** · **[下载完整作品](https://github.com/imini-pku/cat-city-letters/releases/latest)**

## 玩法与内容

- 猫城原版与燕园猫协版两套故事内容。
- 七日救助流程、分支事件、地图遇见、猫咪档案与阶段性结局。
- 资金、猫粮、医疗名额和行动点共同限制可执行的选择。
- 本地存档与回放校验，支持续周、成就、图鉴、音效及周报分享。
- 3 分钟演示模式，便于快速体验关键情节。

居民反馈与规则解读为本地预写内容，未接入在线 AI。游戏状态、资源变化和结局均由固定规则计算，核心流程断网可玩。

## 本地运行

下载并解压完整作品，打开 `index.html`；Windows 也可双击 `开始试玩.bat`。如浏览器限制本地文件，请在项目目录运行：

```console
python -m http.server 4173
```

打开 `http://localhost:4173/`。游戏无需安装前端依赖，也不需要账号。
